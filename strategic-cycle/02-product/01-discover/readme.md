# Discover Phase — Product Cycle

**Inputs**: Strategic OKRs, Operations bug/feedback patterns, market data  
**Outputs**: Research report, personas, user journey maps, opportunity assessment

Frame the problem space. Synthesise user interviews, survey data, and competitive analysis aligned with strategic OKRs. Produce actionable opportunity assessments with confidence levels.

---

## Reference

### Participants
Product Manager, UX Researcher, Tech Lead

### Activity
Problem framing, user interviews, surveys, competitive analysis, feasibility assessment

### Profile
| Dimension | Value |
|---|---|
| Execution / Exploration | 20% / 80% |
| AI Suitability | Medium |
| Key Methodology | Design Thinking, Jobs-to-be-Done, User Research (contextual inquiry, diary studies), Competitive Analysis |
| Key Decisions | Problem to solve, target users, market opportunity, go/no-go |
| Key Human Input | Problem framing empathy, research question design, interpreting unspoken user needs, bias detection |
| KPIs | Research velocity (insights per sprint), user need validation rate, confidence in problem definition |

### Cycle I/O
| Direction | Partner | Signal | KPI |
|---|---|---|---|
| Incoming | Strategic | OKRs, budget allocation, constraints, strategic priorities | OKR alignment score, constraint clarity rating |
| Incoming | Operations | Bug patterns, feature requests, usage friction, trend analysis | Pattern-to-backlog conversion rate, actionability score |
| Incoming | Development | Feasibility estimates, delivery timelines | Estimate accuracy |
| External | Target users | User research participants, interview responses, survey answers | Recruitment velocity, response rate |
| External | Competitive landscape | Competitor product changes, market positioning shifts | Intelligence timeliness, coverage breadth |
