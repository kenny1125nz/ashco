# Observe Phase — Product Cycle

**Inputs**: Usage analytics, satisfaction surveys, NPS  
**Outputs**: Learning report, iteration candidates, roadmap refresh

Analyse feature adoption, funnel metrics, and user feedback against the success hypotheses defined in the Define phase. Update the roadmap with iteration candidates and measurement-driven insights.

---

## Reference

### Participants
Product Manager, Data / Analytics

### Activity
Outcome vs hypothesis analysis, funnel metrics, qualitative feedback

### Profile
| Dimension | Value |
|---|---|
| Execution / Exploration | 20% / 80% |
| AI Suitability | High |
| Key Methodology | Outcome-Driven Development, Funnel Analysis, Cohort Analysis, Customer Satisfaction Tracking (NPS / CSAT) |
| Key Decisions | Iterate, pivot, or stop; next hypothesis; roadmap refresh |
| Key Human Input | Context-rich metric interpretation, connecting quantitative signal to qualitative context, long-term product intuition |
| KPIs | Metric-to-action conversion rate, learning cycle time, data-informed decision % |

### Cycle I/O
| Direction | Partner | Signal | KPI |
|---|---|---|---|
| Outgoing | Strategic | Outcome reports, adoption metrics, portfolio health | Report timeliness, metric accuracy, insight actionability |
| Outgoing | Launch & Marketing | Feature details, release schedule, value propositions | Schedule accuracy, last-minute change frequency |
| Incoming | Launch & Marketing | Market response data, positioning requirements, customer feedback themes | Feedback incorporation rate, market signal relevance |
| Incoming | Operations | Bug patterns, feature requests, usage friction, trend analysis | Pattern-to-backlog conversion rate, feedback freshness |
| Outgoing | Operations | Hotfixes, patch releases, known issues, runbook updates | Patch deployment timeliness, known-issue documentation quality |
| Incoming | Development | Feasibility estimates, delivery timelines, quality data | Estimate accuracy, quality data completeness |
| Outgoing | Development | Design spec, acceptance criteria, priorities | Spec clarity score, criteria completeness, priority stability |
