# Design Phase — Product Cycle

**Inputs**: PRD, personas  
**Outputs**: Approved design spec, design system updates

Produce wireframes, information architecture, and visual designs that meet the PRD requirements. Conduct usability testing and iterate. Finalise the design spec for handoff to Development.

---

## Reference

### Participants
UX / UI Designer, Product Manager

### Activity
Wireframes, information architecture, visual design, prototypes, usability testing

### Profile
| Dimension | Value |
|---|---|
| Execution / Exploration | 50% / 50% |
| AI Suitability | Medium-High |
| Key Methodology | Iterative Design, Design Systems, Usability Testing (formative / summative), Accessibility Standards (WCAG) |
| Key Decisions | Design direction, interaction patterns, information architecture, visual language |
| Key Human Input | Creative direction, brand consistency, inclusive design judgment, aesthetic taste |
| KPIs | Design iteration cycle time, usability defect rate, design-to-dev handoff clarity score |

### Cycle I/O
| Direction | Partner | Signal | KPI |
|---|---|---|---|
| Incoming | Product (Define) | PRD, personas, success metrics | Spec clarity score |
| Outgoing | Product (Execute) | Approved design spec, design system updates | Design-to-dev handoff clarity score |
| Outgoing | Development | Design spec, system context, non-functional requirements | Spec clarity score |
