# Feed Back Phase — Operations Cycle

**Inputs**: Ticket patterns, feature requests, usage bottlenecks  
**Outputs**: Insight reports, product feedback, trend analysis

Synthesise support patterns and feature requests into actionable insights for the Product Cycle. Identify recurring issues, usage bottlenecks, and trending feature gaps with supporting data.

---

## Reference

### Participants
Customer Support, Customer Success, Product Manager

### Activity
Synthesise themes, surface actionable insights to Product Cycle

### Profile
| Dimension | Value |
|---|---|
| Execution / Exploration | 20% / 80% |
| AI Suitability | High |
| Key Methodology | Trend Analysis, Root Cause Categorisation, Sentiment Tracking, Closed-Loop Feedback |
| Key Decisions | What to escalate to Product, priority and severity classification, feature request triage |
| Key Human Input | Strategic prioritisation of what to escalate, connecting pattern to business impact, long-running context memory |
| KPIs | Actionable insight rate, feedback cycle time, Product team adoption of insights, trend detection lead time |

### Cycle I/O
| Direction | Partner | Signal | KPI |
|---|---|---|---|
| Outgoing | Product | Bug patterns, feature requests, usage friction, trend analysis | Insight relevance score, Product adoption rate of feedback |
| Incoming | Operations (Resolve) | Resolved tickets, incident patterns | Data completeness, pattern quality |
