# Measure Phase — Launch & Marketing Cycle

**Inputs**: Campaign reach, conversion funnel, pipeline generated  
**Outputs**: Campaign report, lessons learned, optimisation recommendations

Run attribution analysis and ROI assessment on campaign performance. Produce a lessons-learned report with actionable optimisation recommendations for the next campaign cycle.

---

## Reference

### Participants
Marketing, Data / Analytics

### Activity
Attribution analysis, ROI assessment, A/B test evaluation

### Profile
| Dimension | Value |
|---|---|
| Execution / Exploration | 30% / 70% |
| AI Suitability | High |
| Key Methodology | Attribution Modeling (Multi-Touch, Last-Touch), Funnel Analysis, A/B Testing, Cohort Analysis |
| Key Decisions | Optimisation priorities, budget reallocation, campaign go/no-go |
| Key Human Input | Business context for attribution interpretation, qualitative market insight, strategic narrative |
| KPIs | Attribution accuracy, reporting latency, optimisation iteration speed, ROI per channel |

### Cycle I/O
| Direction | Partner | Signal | KPI |
|---|---|---|---|
| Outgoing | Strategic | Campaign performance reports | Report timeliness, data accuracy vs actuals |
| Outgoing | Product | Market response data, positioning requirements, customer feedback themes | Feedback incorporation rate, insight-to-action time |
