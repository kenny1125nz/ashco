# Review Phase — Strategic Cycle

**Inputs**: Sub-cycle outcome reports, portfolio dashboards, financial results  
**Outputs**: Updated strategic plan, pivots, reprioritised OKRs

Assess sub-cycle outcomes against OKRs. Evaluate whether Product delivery enabled or blocked strategic goals. Produce adjusted direction, reprioritised OKRs, and any pivot or resource reallocation decisions.

---

## Reference

### Participants
Board of Directors, CEO

### Activity
Assess outcomes against OKRs, evaluate whether Product delivery enabled or blocked strategic goals, adjust direction

### Profile
| Dimension | Value |
|---|---|
| Execution / Exploration | 30% / 70% |
| AI Suitability | High |
| Key Methodology | OKR Review, Variance Analysis, Balanced Scorecard, Strategy Review Cadence, Sub-Cycle Dependency Tracking |
| Key Decisions | Pivots, strategic adjustments, OKR refresh, re-prioritisation, resource reallocation |
| Key Human Input | Qualitative interpretation of ambiguous signals, board-level discernment, conviction under uncertainty |
| KPIs | Pivot velocity, strategic decision accuracy, review cadence adherence, sub-cycle blockage detection time |

### Cycle I/O
| Direction | Partner | Signal | KPI |
